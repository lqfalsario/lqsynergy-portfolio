How updates work

From edit to live site.

  1. Open the relevant editor card and sign in to your own account.
  2. Edit the content and commit changes to the GitHub main branch.
  3. Check the publishing workflow and verify on the live site.

Access and privacy

Your accounts stay protected.

This page is an owner shortcut hub, not a private sign-in system. It is publicly reachable on GitHub Pages, but it does not display credentials, private visitor details or inbox contents. GitHub, Google, Gmail and Calendly require their own authenticated accounts to manage data.

For a truly private dashboard with editable settings or saved chatbot conversations, a secure backend and sign-in service would be required.
