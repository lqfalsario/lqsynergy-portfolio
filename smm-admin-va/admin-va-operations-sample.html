03 / DOCUMENTATION

A lightweight SOP for fewer loose ends.

A five-step operating routine showing how an Administrative VA can move requests from intake to documented completion.

01

Capture

Record incoming messages, requests, owners and due dates.

02

Prioritize

Tag urgent, standard and reference-only items consistently.

03

Coordinate

Confirm calendars, ask clarifying questions and route approvals.

04

Document

Update the shared task log, store files and maintain versions.

05

Report

Summarize completed work, open risks and the next priority.

File naming convention · Example onlyYYYY-MM-DD_Client_Project_Document_v01.ext

Organize files by Client → Project → Year → Deliverables; keep an archive for superseded versions.
